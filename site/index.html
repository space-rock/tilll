For developers

Create invoices from your server. Open the checkout with one script tag.

Embed the checkout

<script src="https://pay.example.com/checkout.js"></script>
<button data-tilll-invoice="inv_...">Pay with crypto</button>

Create an invoice

curl -X POST https://pay.example.com/v1/invoices \
  -H "Authorization: Bearer $MERCHANT_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"amount":"5.00","description":"Order 1042"}'

Self-host in 5 minutes

Four commands and a dashboard. No funds needed.

Terminal

git clone {{cloneTarget}} tilll && cd tilll
pnpm install
pnpm tilll init
docker compose up --build

Set your NEAR account in .env, then open http://localhost:8080/dashboard and sign in with the secret in the same file.
